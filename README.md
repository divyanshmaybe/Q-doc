# Q-Doc

> A basic checkup, in your own language, without the wait.

Q-Doc builds AI-powered health screening kiosks for government hospitals and public spaces across India. One visit, one conversation, in the patient's own language — screening and answer in the same sitting. No appointment. No queue.

## About

Q-Doc is a landing page for an AI-powered health screening solution designed to make basic medical checkups accessible to everyone in India, regardless of language or location.

## Features

- 🌐 Multilingual AI health screening
- 🏥 Designed for government hospitals and public spaces
- ⚡ No appointment needed — instant screening
- 📱 Responsive design with dark mode support

## Tech

Built with vanilla HTML, CSS, and JavaScript.
